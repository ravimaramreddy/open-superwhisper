OpenSuperwhisper · implementation plan

Your words, in natural English.

Keep Qwen + Gemma E4B on Studio and Qwen + S1-mini on this Mac. Improve recognition of names, make formatting deliberate, and keep suspicious edits reviewable.

A small personal dictionary

Settings gains preferred spellings and optional exact mishearings. History gains “Remember a correction.” Saving a word affects future dictation; it never rewrites saved originals. Start with the existing product-name hints and let every entry be edited or removed.

Limit: 32 terms, four aliases per term. Matching is whole-phrase, preserves quoted/code text and already-correct names, and rejects conflicting entries. No broad fuzzy substitutions.

One clear cleanup choice

“Clean English” fixes grammar and false starts. “Rewrite with Studio” remains an explicit action. Choose prose, paragraphs or a list. The local S1 model uses its documented prose/list controls; paragraph guidance belongs to Studio.

Keep meaning reviewable

Check numbers, negation, known names and literal technical text. On suspicious changes, keep the original as the delivered text and retain the proposed edit for comparison and explicit copying. These checks catch selected errors; they cannot prove meaning is unchanged.

Implementation and verification

  1. Prove vocabulary support using the installed runtime and existing Studio speech service. Wire supported recognition hints without altering shared services.
  2. Add validated settings, dictionary processing, formatting and review metadata with backward-compatible defaults.
  3. Test both real inference routes, failure/fallback behavior, settings persistence, aliases and meaning checks. Reuse public test audio; personal speech evaluation remains a later opt-in step.
  4. Independently review the changes, run tests and packaging, inspect the UI, update the installed app and existing PR, then monitor CI.

Chosen defaults

No new models, paid services, permissions or cloud endpoints. Existing hotkey, login, cleanup and history preferences stay intact. No automatic audio retention or background collection. Existing history loads unchanged; optional review metadata is additive.

Design follows the existing OpenSuperwhisper tokens: parchment, system type and blue controls. This plan records the accepted scope and does not require another approval.
